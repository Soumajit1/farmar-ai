# AgriLink AI - GitHub Pages Deployment

This package keeps the complete current project.

GitHub Pages publishes the static frontend files:
- HTML
- CSS
- JavaScript
- assets

The Node.js backend and MySQL database are NOT executed by GitHub Pages.
They must be hosted separately for login, database operations, transactions,
FPO APIs, etc. to work on the public website.

GitHub Pages:
Settings -> Pages -> Build and deployment -> Source -> GitHub Actions
